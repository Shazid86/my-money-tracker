Aureus is a high-performance personal finance tracker engineered for fast expense logging, real-time budget management, and visual cash flow analytics. Built using Next.js, React, TypeScript, Tailwind CSS, and shadcn/ui.

---



## ✨ Features

 *📊* *Interactive Financial Dashboard:** Real-time summary of total balances, monthly income, and expense breakdown.

 *💳* *Transaction Ledger:** Add, edit, filter, and delete income or expense entries seamlessly.

 *📈* *Visual Analytics:** Interactive charts tracking monthly spending categories and trend lines.

 *🎯* *Budget Limits & Alerts:** Define category caps and visually monitor budget consumption.

 *🎨* *Accessible UI Components:** Modern, accessible interface primitives powered by shadcn/ui.

 *🌓* *Responsive Layout:** Fluid layout crafted with Tailwind CSS for mobile, tablet, and desktop views.

 *🔐* *Client-Side Data Integrity:** Strongly typed state management keeping your financial data secure.

## 🚀 Getting Started



### Prerequisites

Ensure you have Node.js and npm installed:

- Node.js: `>= 18.17.0`
- npm: `>= 9.0.0`



### Installation & Local Run

1. Clone the repository:
  ```bash

   git clone [[https://github.com/Shazid86/my-money-tracker.git](https://github.com/Shazid86/my-money-tracker.git)](https://github.com/Shazid86/my-money-tracker.git](https://github.com/Shazid86/my-money-tracker.git))

   cd my-money-tracker
  ```
2. Install project dependencies:

npm install

1. Start the local development server:

npm run dev

1.  Open [http://localhost:3000](http://localhost:3000) in your browser.
